### Mục tiêu Tuần 1

- Làm quen với nền tảng Amazon Web Services (AWS).
- Tìm hiểu kiến trúc Serverless và các thành phần cơ bản của một ứng dụng web trên AWS.
- Tìm hiểu kiến thức cơ bản về Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, Amazon DynamoDB và AWS IAM.
- Xây dựng kiến thức nền tảng để chuẩn bị cho việc thiết kế và triển khai hệ thống CloudMenu trên AWS.

### Thành tựu Tuần 1

- Nắm được kiến thức nền tảng về AWS Cloud và kiến trúc Serverless.
- Hiểu các thành phần cơ bản của một ứng dụng web, bao gồm Frontend, API, Backend và Database.
- Hiểu vai trò cơ bản của Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, Amazon DynamoDB và AWS IAM.
- Hiểu luồng Request và luồng dữ liệu cơ bản của một ứng dụng Serverless trên AWS.
- Xây dựng được nền tảng kiến thức cần thiết để thiết kế và triển khai hệ thống CloudMenu trong các tuần tiếp theo.
