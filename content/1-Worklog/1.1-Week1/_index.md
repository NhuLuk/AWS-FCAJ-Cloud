### Week 1 Objectives

- Become familiar with the Amazon Web Services (AWS) platform.
- Learn about Serverless Architecture and the basic components of a web application on AWS.
- Explore the fundamentals of Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, Amazon DynamoDB, and AWS IAM.
- Build foundational knowledge to prepare for designing and deploying the CloudMenu system on AWS.

**Duration:** 22/06/2026 - 26/06/2026

### Week 1 Achievements

- Gained foundational knowledge of AWS Cloud and Serverless Architecture.
- Understood the basic components of a web application, including Frontend, API, Backend, and Database.
- Understood the basic roles of Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, Amazon DynamoDB, and AWS IAM.
