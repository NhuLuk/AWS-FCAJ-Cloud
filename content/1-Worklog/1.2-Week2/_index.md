### Week 2 Objectives

- Learn about AWS Identity and Access Management (IAM) and the principles of access control on AWS.
- Learn about Amazon S3 and how it can be used to store static website content.
- Learn about Amazon CloudFront and how it distributes frontend content.
- Practice deploying a static website using Amazon S3 and Amazon CloudFront.
- Strengthen knowledge of frontend hosting to prepare for deploying the CloudMenu interface on AWS.

**Duration:** 29/06/2026 - 03/07/2026

### Week 2 Achievements

- Understood the role of AWS IAM in managing identities and access permissions for AWS resources.
- Learned the basic IAM components, including Users, Roles, and Policies.
- Understood how Amazon S3 stores HTML, CSS, JavaScript, and image files for a static website.
- Learned how Amazon CloudFront distributes frontend content from Amazon S3 over HTTPS.
- Understood the relationship between a CloudFront Distribution and an S3 Origin.
- Practiced deploying and accessing frontend content through a CloudFront Domain.
- Built foundational knowledge of S3, CloudFront, and IAM for deploying the CloudMenu interface on AWS.
