During the **First Cloud AI Journey** program, I maintained a worklog for **8 weeks**, from **22/06/2026 to 15/08/2026**. The worklog documents the process of learning AWS services, developing knowledge of Serverless Architecture, and gradually applying these technologies to build the **CloudMenu** system.

---

**Week 1 (22/06 - 26/06):** [AWS Cloud and Serverless Fundamentals](1.1-week1/)

- Learned the fundamentals of AWS Cloud and its core service categories
- Explored Serverless Architecture and the main components of a web application
- Learned the basics of Amazon S3, CloudFront, API Gateway, Lambda, DynamoDB, and IAM
- Built foundational knowledge for developing the CloudMenu system

---

**Week 2 (29/06 - 03/07):** [IAM, Amazon S3, and Amazon CloudFront](1.2-week2/)

- Learned about AWS IAM and access management principles
- Explored Amazon S3 for storing frontend resources
- Learned how Amazon CloudFront distributes content over HTTPS
- Practiced deploying a static website using Amazon S3 and CloudFront

---

**Week 3 (06/07 - 10/07):** [Amazon DynamoDB and Data Design](1.3-week3/)

- Learned about NoSQL databases and Amazon DynamoDB
- Explored Tables, Items, Attributes, and Partition Keys
- Practiced creating, reading, and updating data in DynamoDB
- Designed the order data structure for the CloudMenu system

---

**Week 4 (13/07 - 17/07):** [AWS Lambda and Serverless Backend](1.4-week4/)

- Learned about AWS Lambda and the Function as a Service (FaaS) model
- Practiced creating, configuring, and testing Lambda Functions
- Connected AWS Lambda with Amazon DynamoDB using Boto3
- Built Lambda Functions for creating, retrieving, and updating order status

---

**Week 5 (20/07 - 24/07):** [Amazon API Gateway and REST API](1.5-week5/)

- Learned about Amazon API Gateway, REST APIs, and HTTP methods
- Built APIs for the CloudMenu order processing workflow
- Integrated Amazon API Gateway with AWS Lambda and Amazon DynamoDB
- Configured CORS and connected the frontend with the backend

---

**Week 6 (27/07 - 31/07):** [CloudMenu System Analysis and Development](1.6-week6/)

- Analyzed system requirements and identified the main CloudMenu features
- Built the table identification and QR Code-based ordering mechanism
- Developed the customer interface with menu, cart, and order submission features
- Developed the Kitchen interface for monitoring and updating order status

---

**Week 7 (03/08 - 07/08):** [CloudMenu Deployment and Integration on AWS](1.7-week7/)

- Completed the main components of the CloudMenu system
- Deployed the frontend to Amazon S3 and distributed it through Amazon CloudFront
- Integrated the frontend with API Gateway, Lambda, and DynamoDB
- Tested the complete workflow from customer ordering to kitchen processing and order completion

---

**Week 8 (10/08 - 15/08):** [CloudMenu Finalization and Program Summary](1.8-week8/)

- Built and completed the system statistics Dashboard
- Completed order time tracking and order status features
- Tested, debugged, and finalized the CloudMenu system
- Completed architecture diagrams, workflows, README, Workshop, and project documentation
- Summarized the knowledge and skills gained throughout the First Cloud AI Journey program
