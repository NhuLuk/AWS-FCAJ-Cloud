## 5. Self Evaluation

During my internship at **Amazon Web Services Vietnam Co., Ltd.** from **June 22, 2026 to August 15, 2026**, I had the opportunity to participate in the **First Cloud AI Journey (FCAJ)** program and develop **EduWallet**, a personal finance management application designed for students and built on Amazon Web Services (AWS).

Throughout the internship, I applied the knowledge acquired at university in software engineering, database systems, and cloud computing to design and develop a cloud-native web application using **Next.js**, **NestJS**, and various AWS services.

My responsibilities in the project included:

- Designing the system architecture based on AWS cloud services.
- Developing the frontend with Next.js and the backend with NestJS.
- Deploying cloud infrastructure using Terraform following the Infrastructure as Code (IaC) approach.
- Integrating AWS services such as Amazon VPC, Amazon ECS Fargate, Amazon ECR, Amazon RDS PostgreSQL, Amazon Cognito, AWS Amplify, Amazon CloudFront, Application Load Balancer, Amazon CloudWatch, and AWS Secrets Manager.
- Preparing workshop documentation, architecture diagrams, and deployment guides.
- Collaborating with team members to analyze requirements, design solutions, and complete the project.

Besides improving my technical knowledge, I also developed communication skills, teamwork, time management, and the ability to learn new technologies independently in a professional working environment.
