## 5.2. Prerequisites

Before deploying CloudMenu on AWS, an AWS account, the application source code, and the required tools must be prepared.

CloudMenu is built using a Serverless architecture with several AWS services, including Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, Amazon DynamoDB, and AWS Identity and Access Management (IAM).

In this workshop, the required AWS resources will be created and configured step by step. The frontend and backend will then be deployed and connected before testing the complete CloudMenu workflow.

The following prerequisites are required:

- An AWS account with permissions to create and configure the required resources.
- Access to the AWS Management Console.
- CloudMenu source code.
- A web browser for accessing the AWS Management Console and testing the application.
- A mobile device capable of scanning QR codes for testing the Customer Interface.
- A stable Internet connection.
