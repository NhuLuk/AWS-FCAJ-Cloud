### [Blog 1 - TURNING MILLIONS OF CONTRACTS INTO USEFUL DATA WITH DOCZY.AI AND GENERATIVE AI ON AWS](3.1-Blog1/)

This blog introduces how **Doczy.ai by AArete** uses Generative AI and AWS services to automate contract analysis. The solution combines **Amazon Bedrock, Amazon Textract, Amazon S3, AWS Lambda, Amazon ECS**, and other services to transform millions of pages of unstructured documents into useful data. One of its key techniques is **Smart Chunking**, which helps preserve document structure and context during processing.

### [Blog 2 - BUILDING A MULTI-INTERFACE AI ASSISTANT WITH AMAZON Q BUSINESS AND SLACK ON AWS](3.2-Blog2/)

This blog introduces an architecture for building a **multi-interface AI Assistant with Amazon Q Business and Slack**, allowing users to access internal organizational knowledge directly from the tools they already use. The solution applies **Retrieval Augmented Generation (RAG)** and combines **Amazon Q Business, Amazon Kendra, Amazon S3, AWS Lambda, Amazon EventBridge, and Amazon CloudFront** to retrieve information, generate responses, and provide clickable references so users can verify the sources behind AI-generated answers.

### [Blog 3 - HOW AGENTIC AI IS TRANSFORMING GAME INFRASTRUCTURE MANAGEMENT ON AWS](3.3-Blog3/)

This blog explores how **Agentic AI** can support the management of complex game infrastructure on AWS. The architecture uses **Amazon Bedrock AgentCore** together with specialized AI agents such as the **Game Agent Orchestrator, GameLift Servers Specialist, EKS Specialist, and Cost Specialist**. These agents allow operations teams to interact with infrastructure using natural language, analyze observability data, troubleshoot issues, and receive optimization recommendations, helping reduce context switching and improve game infrastructure operations.
